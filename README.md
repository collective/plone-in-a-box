# Plone in a Box™
An easy way to deploy a cloud server running Plone 6 with the new Volto React front end.

Currently supported cloud providers:
* Amazon AWS (Plone 5.2, Plone 6.0 alpha 1)
* Linode (Plone 6.0.0b3, Volto 16.0.0-alpha.42)
* DigitalOcean (Plone 5.2 under review, Plone 6.0 alpha 1 coming soon)
