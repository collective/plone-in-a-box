Try Volto Light Theme

Your own Plone 6 site with Volto Light Theme in about 10 minutes.

It runs on a cloud server in your own account, set up by Plone in a Box. A small server costs a few cents an hour, paid to the cloud provider; delete it when you're done, which deletes the site too.

Launch on AWS Deploy on Linode DigitalOcean or Hetzner
  1. Choose a provider below and create the server. You fill in two passwords: one for admin, and one for the demo login you'll share.
  2. Open the server's address in a browser. Setup takes about 10 minutes, and the page shows how far it got.
  3. Log in as demo with the demo password, then edit the home page and try the theme's settings for the logo, colours, header and footer.

The demo login has the role Editor: it can do what that role allows on the site, and nothing more. Share it with whoever you want to try Volto Light Theme.

The site has no domain, so it uses plain HTTP and passwords cross the network unencrypted. Choose passwords you don't use anywhere else.

Amazon AWS

  1. Sign in to the AWS console, then click Launch on AWS: a form with Volto Light Theme and the demo login filled in.
  2. Fill in AdminPassword and DemoPassword (at least 12 characters each), and click Create stack.
  3. When the stack says CREATE_COMPLETE, open the SiteURL on its Outputs tab.

The default t3.small server costs more than the other providers' 1 GB ones. To delete it, delete the stack.

Linode (Akamai)

Linode can't fill in the form from a link, so you paste a few values into it.

  1. Log in to Cloud Manager, open the Plone in a Box StackScript, and click Deploy New Linode.
  2. Fill in these fields, and leave the others as they are:
    Plone admin passworda password of at least 12 characters, for you
    Demo logindemo
    Frontend imageghcr.io/collective/plone-in-a-box-frontend:19-vlt
    Demo login passwordat least 12 characters, for the people you let try it
  3. Choose Ubuntu 26.04 LTS, a region, a 1 GB Nanode and No firewall, set a root password, and click Create Linode.

Then open the Linode's IP address in a browser. To delete it: ⋯ → Delete.

DigitalOcean and Hetzner

Create an Ubuntu 26.04 server with 1 GB of memory or more, and paste these lines into Additional Options → Startup scripts (DigitalOcean) or Cloud config (Hetzner). Replace CHANGE-ME with an admin password and CHANGE-ME-TOO with a demo password, each at least 12 characters:

#!/bin/bash
export ADMIN_PASSWORD='CHANGE-ME'
export FRONTEND_IMAGE='ghcr.io/collective/plone-in-a-box-frontend:19-vlt'
export DEMO_USER='demo'
export DEMO_PASSWORD='CHANGE-ME-TOO'
curl -fsSL --retry 10 --retry-all-errors -o /root/plone-in-a-box.sh https://raw.githubusercontent.com/tkimnguyen/plone-in-a-box/2.17/src/StackScript && bash /root/plone-in-a-box.sh

Then open the server's IP address in a browser. More detail: DigitalOcean, Hetzner.

Forgot the demo password?

Log in as admin, open Site Setup → Users, click demo and set a new one. If you left it empty, setup made one up: open your provider's browser console (Linode's Launch LISH Console, DigitalOcean's Access → Launch Droplet Console, AWS's Connect → EC2 Instance Connect, Hetzner's >_ Console) and run:

sudo cat /root/plone-credentials.txt
